**Демо онлайн:** https://nallsy.github.io/zhivoy-cekh1/ (после включения GitHub Pages, см. ниже)

## О проекте

«Живой цех» — работающий в браузере цифровой двойник сборочной линии: склад → сварка → окраска → сборка → контроль качества. Двойник не проигрывает заготовленную анимацию, а моделирует линию по минутам: время цикла каждого поста, износ оборудования, отказы и ремонты, буферы между постами, брак и доработку. Все показатели, прогнозы и рекомендации считаются из состояния модели.

## Что умеет MVP

- **Карта линии в реальном времени:** состояние каждого поста (работает, ждёт кузов, заблокирован, простой, ППР), прогресс цикла, загрузка, температура, заполнение буферов.
- **Показатели смены:** выпуск против плана, OEE с разбивкой на доступность, производительность и качество, простой, брак, незавершённое производство, фактический такт.
- **ИИ-прогноз отказов:** вероятность отказа каждого поста в ближайшие 60 минут и вклад факторов (время цикла, микроостановки, температура привода). Модель обучена на 90 днях истории — см. [REPORT.md](REPORT.md).
- **Поиск узкого места:** пост с максимальной занятостью за последний час, а не заданная заранее строка.
- **Что если:** пять вариантов решения (ничего не менять, ППР сейчас, резервный пост, ППР + резерв, перенос ППР). Каждый вариант прогоняется 40 раз до конца смены методом Монте-Карло на одинаковых случайных сценариях, с диапазоном результата.
- **Рекомендация и применение решения:** когда риск превышает порог, двойник сам сравнивает варианты и предлагает лучший; руководитель применяет его одной кнопкой, и линия реагирует.
- **Прогноз выпуска к концу смены** с диапазоном, журнал событий, экономический эффект в тенге и текстовая сводка смены.
- Работает полностью локально: без сервера, внешних API и установки зависимостей.

## Как устроено

```
Симулятор линии (sim.js)
  ├─ посты: время цикла, износ, отказы, ремонт, ППР, резервный пост
  ├─ буферы между постами, брак и доработка
  └─ датчики: время цикла, микроостановки, температура привода
        │
        ├─► показатели: выпуск, OEE, простой, брак, WIP, узкое место
        ├─► модель риска (risk_model.js ← обучена в train_risk_model.py)
        └─► Монте-Карло «что если»: копии линии прогоняются до конца смены
                │
                └─► рекомендация и экономический эффект → интерфейс (app.js)
```

Модель износа и датчиков в `sim.js` и в `train_risk_model.py` одна и та же, поэтому обученная на истории модель корректно работает на данных симуляции. В промышленной версии симулятор заменяется потоком данных MES, SCADA и 1С, а модель переобучается на реальных логах.

## ИИ-модель

- **Задача:** вероятность отказа поста в ближайшие 60 минут.
- **Признаки за последние 30 минут:** рост времени цикла к номиналу, доля циклов с микроостановками, превышение температуры привода.
- **Модель:** логистическая регрессия (scikit-learn), обучение на днях 1–70, проверка на днях 71–90.
- **Качество:** ROC-AUC около 0,85 на проверочных днях; полные метрики в [REPORT.md](REPORT.md).
- **Данные:** [welding_history_90d.csv](welding_history_90d.csv) — 90 дней наблюдений сварочного робота с метками отказов.

Переобучить модель:

```
pip install -r requirements.txt
python train_risk_model.py
```

Скрипт заново сгенерирует историю, обучит модель и обновит `risk_model.js`, `risk_model.json` и `REPORT.md`.

## Важно о данных

Все данные синтетические и не являются производственными данными АО «Группа компаний АЛЛЮР». Параметры линии, план, маржа и экономический эффект — демонстрационные допущения, их можно заменить реальными значениями.

## Запуск

Откройте `index.html` в браузере — установка не нужна.

Или через локальный сервер:

```
python -m http.server 8000
```

и откройте `http://localhost:8000`.

**GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)` → Save. Через 1–2 минуты сайт будет доступен по адресу `https://nallsy.github.io/zhivoy-cekh1/`.

## Сценарий демонстрации

Сценарий фиксирован (seed 30), поэтому без вмешательства смена всегда идёт одинаково.

1. Нажать «Запустить смену», скорость 3 мин/с. Сварочный робот WR-04 сразу в зоне риска (около 36%): предаварийный режим.
2. Около 10:40 риск растёт выше 50%. ИИ показывает главный фактор (температура привода) и сам сравнивает варианты: лучший — «ППР сейчас + резервный пост», около +17 авто к концу смены.
3. **Вариант А:** нажать «Применить». Робот уходит на ППР на 25 минут, резервный пост держит поток, прогноз выпуска поднимается до плана.
4. **Вариант Б:** ничего не делать. Около 11:48 WR-04 отказывает, очередь перед сваркой растёт, участки выше по потоку блокируются, прогноз падает. Для мгновенной демонстрации есть кнопка «Внести отказ WR-04».
5. Таблица «Что если»: сравнение всех вариантов с диапазонами и расчёт эффекта в тенге.
6. «Сформировать сводку»: итоги смены текстом.

Результат одной смены при решении в 10:40: без вмешательства — 86 авто и отказ робота; ППР + резервный пост — 103 авто при плане 100.
